# Фотографии

`dress1.jpg` и `dress2.jpg` — ваши изображения для блока дресс-кода. Они показываются целиком в белых рамках и открываются на весь экран при нажатии. Настройки находятся в `content/wedding.js` → `photos.dressLeft` и `photos.dressRight`.

В приглашении используются ваши фотографии: `1.jpg` для обложки, `6.jpg` и `8.jpg` для коллажа; `loc4.jpg`, `loc1.jpg` и `loc2.jpg` для локации. Размеры и кадрирование заданы в `content/wedding.js` → `photos`.

Ссылки на файлы и кадрирование задаются в `content/wedding.js` → `photos`. Укажите новые относительные пути, описание `alt` и при необходимости `position` (`center`, `center 30%` и т. п.).

Остальные загруженные вами фотографии сохранены для дальнейшего выбора и замены. Страница загружает только снимки, указанные в настройках.

Обложка занимает ширину основного контейнера, без надписей поверх снимка. Текущее фото `1.jpg` имеет размер 853 × 1280 px. Для большей детализации замените его оригиналом, обновите `width` и `height` в настройках. Для широкой обложки желательно от 2000 px по ширине. Подойдут JPG и WebP. Используйте имена файлов без пробелов.
