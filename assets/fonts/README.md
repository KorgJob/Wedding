# Шрифты

В проекте локально хранятся **Bodoni Moda** (обычный и курсив), Manrope, Prata и ваш **Classica Two**. Шрифты загружаются из этой папки. Лицензии свободных шрифтов находятся рядом с файлами.

Classica Two используется для имён на основной странице. В письме используется более строгий акцентный шрифт. Знак `&` набран акцентным курсивом. Для Classica Two подключён файл `Classica Two.ttf`; заменять его следует с сохранением названия или с обновлением пути в `styles/fonts.css`.

У свободного Bodoni Moda нет кириллицы. Поэтому английский заголовок, цифры и знак `&` используют Bodoni Moda, а русские акцентные заголовки — резервный Prata. Это не кириллическая версия Bodoni. Если на устройстве установлен Bodoni с кириллицей, он используется первым.

Чтобы показывать именно Bodoni на русском на всех устройствах:

1. Добавьте вашу лицензированную веб-версию с кириллицей в эту папку, например `bodoni-cyrillic.woff2`.
2. В первом правиле `styles/fonts.css` замените `src` на:

   ```css
   src: url('../assets/fonts/bodoni-cyrillic.woff2') format('woff2');
   ```

Названия шрифтов и порядок подстановки находятся в `styles/tokens.css` (`--font-accent`). Остальной код менять не нужно.
